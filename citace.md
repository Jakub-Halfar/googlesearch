# Citace a zdroje

## Zadání

- [CS50 Web - Search](https://cs50.harvard.edu/web/projects/0/search/) - zadání projektu, požadavky na Google Search, Image Search a Advanced Search.
- [W3C Markup Validation Service](https://validator.w3.org/) - validace HTML.
- [W3C CSS Validation Service](https://jigsaw.w3.org/css-validator/) - validace CSS.

## Použité prompty

Při tvorbě a úpravách projektu byly použity tyto prompty:

1. „Posílám odkaz s podkladem CS50's Web Programming with Python and JavaScript: vytvořte frontend pro Google Search, Google Image Search a Google Advanced Search.“
2. „Navíc k zadání vytvořte další stránku s co největším množstvím formulářových prvků. Přidejte na všechny stránky odkazy na HTML/CSS validátory, citace a zdroje a portfolio. Zkontrolujte funkčnost odkazů.“
3. „Upravte vzhled projektu z matrix stylu na moderní portfolio styl s tmavým navy pozadím, gradienty, barevnými akcenty, zaoblenými prvky a responzivním designem. Zachovejte funkčnost všech vyhledávacích formulářů.“
4. „Odstraňte nápis portfolio z levého rohu navigace.“

Kód byl vytvořen a upraven pomocí AI asistenta podle uvedeného zadání. Odkazy na validátory jsou nastavené pro stránky hostované na GitHub Pages v repozitáři `Jakub-Halfar/googlesearch`.
